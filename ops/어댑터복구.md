# 어댑터 9종 복구 — 포트1 재기동 (2026-10-02)

노트북 서버가 재기동되면서 포트1이 **구 체크포인트(checkpoints/jeff-0.8b)+어댑터 없음** 상태로 올라왔다. PWA의 "재가동 필요" 표시는 정상 판정이다.

## 노트북 PowerShell에서 (재부팅 복구 스크립트로 자동 기동 해도 됨)
이미 켜진 서버 창 3개는 그대로 두고 **포트1(8765) 창만** 찾아서:
- 창 안에서 `Ctrl+C` → 완전히 끝날 때까지 대기 → 창 닫기
- (포트1을 못 찾겠으면 모든 jeff-serve 창을 닫아도 된다 — 아래에서 3개 다시 열리게 하는 스크립트가 있다)

그 후 새 PowerShell:
```powershell
cd ~
powershell -ExecutionPolicy Bypass -File .\reboot-recovery.ps1
```
(없으면 먼저: `curl.exe -o reboot-recovery.ps1 https://raw.githubusercontent.com/realizer-1966/jeff-lab/main/ops/reboot-recovery.ps1`)

스크립트가 서버 창 3개를 올바른 구성으로 자동 기동:
- 포트1 = **0.8B v1.2 + 어댑터 9종** (시작 로그에 adapter added 9개)
- 포트2 = 2B / 포트3 = gemma4

35초 후 자동 헬스체크. 끝나면 PWA 새로고침 2회 → 어댑터 카드 배지 "로드됨" 복귀 확인.

※ 스크립트의 키는 별표3("***")으로 기동한다 — 이전 세대와 같은 값이라 PWA 설정도 그대로 동작한다.
※ 기동 로그에서 `added adapter guard` … `legal-clauses` 9줄이 보이면 성공.
